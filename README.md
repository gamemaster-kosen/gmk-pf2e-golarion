# GMK - PF2e: Golarion

Maps of the World of Golarion from the Pathfinder TTRPG with FoundryVTT Integration.

# Module Content

This section details content included in this module.

## [PF1e: Blank] [Map] - Inner Sea Region + Darklands

A hexploration map of the **Inner Sea Region** of **Golarion**; including three layers of the **Darklands**.

"PF1e" means this map is correct and accurate as of the start of PF1e: Age of Lost Omens.

| FoundryVTT Level | Description |
| --- | --- |
| [Golarion - Inner Sea Region - Surface](assets/scenes/inner-sea-region/base.webp) | Surface-layer of Golarion |
| [Darklands - Inner Sea Region - Nar Voth](assets/scenes/darklands/nar-voth.webp) | Top-layer of the Darklands |
| [Darklands - Inner Sea Region - Sekamina](assets/scenes/darklands/sekamina.webp) | Middle-layer of the Darklands |
| [Darklands - Inner Sea Region - Orv](assets/scenes/darklands/orv.webp) | Bottom-layer of the Darklands |

### FoundryVTT Integration(s)

This section details FoundryVTT integrations for this module.

| Integration | Description |
| --- | --- |
| **Notes** | Map Pins linked to Blank Journal Entries. |
| **Regions** | Regions; without defined Behaviors. |

### Additional Notes

This section details useful information.

**Blank Variant:** means this map contains blank foundryvtt integrations (notes, journal entries, regions etc.) -- the intent is to allow GMs that prefer to create and manage their own content to benefit from this module, without the need to "scrub" the content from a "feature-complete" map first.
